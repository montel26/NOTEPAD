# Note It Down - A Simple Text Editor

## Overview
"Note It Down" is a feature-rich text editor designed to provide users with an intuitive and efficient word processing experience. Built with Java Swing, this application emulates the functionality of conventional notepad applications while offering modern enhancements.

## Key Features
- **User-Friendly Interface**: A clean and simple layout that makes it easy to create, edit, and manage text documents.
- **File Management**: Effortlessly create new documents, open existing ones, and save your work with a straightforward file handling system. Supports saving in `.txt` format.
- **Text Editing Tools**: Includes essential text manipulation functions such as cut, copy, paste, and select all.
- **Print Functionality**: Quickly print your documents directly from the application.
- **About Section**: Provides information about the application, enhancing user experience.

## Technologies Used
- **Java**: The primary programming language used.
- **Swing**: For creating the GUI.
- **AWT**: For event handling and printing.

## Getting Started
To run the application, ensure you have Java installed on your system. Compile the Java files and execute the `Notepad` class.

### Prerequisites
- Java Development Kit (JDK)
- Basic understanding of Java programming
